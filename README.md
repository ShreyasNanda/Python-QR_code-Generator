# Pure Python QR Code Generator

A lightweight, educational project that implements a QR code generator entirely from scratch in Python, without relying on any external libraries or third-party packages.

## 🚀 Features
- **Zero Dependencies:** Written using core concepts to handle the logic without needing `pip install` packages like Pillow or qrcode.
- **Educational:** Great for understanding the low-level mechanics of the ISO/IEC 18004 QR code specification, including data encoding, matrix mapping, and structure formatting.
- **Lightweight & Fast:** Minimal overhead and easy to drop straight into other scripts.

---

### Prerequisites
Make sure you have **Python 3.x** installed on your system. No external libraries are required!
